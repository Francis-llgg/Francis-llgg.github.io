# Zilong Zheng — Robotics & Embodied AI

Personal portfolio for Zilong (Francis) Zheng, featuring work in world models,
multimodal perception, motion planning, and real-world robot deployment.

**Live site:** [francis-llgg.github.io](https://francis-llgg.github.io/)

## Highlights

- English-first presentation with a complete Chinese version
- Research and industry experience presented with concise evidence
- Detailed case studies for three robotics and perception projects
- MathBench publication case study with original figures and results

## Local development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Run `npm test` before publishing. The generated GitHub Pages site is stored in
`docs/` and served from the repository's `main` branch.
